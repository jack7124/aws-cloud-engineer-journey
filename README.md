# Hey! This repo is my "AWS Cloud Engineer Journey" through IDX Exchange as an AWS Cloud Engineering intern. 
## Over these 12 weeks, I will be continuing to upload labs, markdown files of those labs or key explanations of AWS concepts, and proof of my progress. 


"Target outcome: AWS Certified Solutions Architect – Associate (SAA-C03) readiness, plus a deployed,
documented GitHub portfolio showing you can operate a real application in production"

"Program positioning: this track does not build an app from scratch. Interns are handed a small, alreadyworking
application (PropertyLite, provided in full in Week 0) and spend all 12 weeks doing what a junior
cloud/DevOps engineer actually does: deploying it, scaling it, securing it, containerizing it, automating its
releases, monitoring it, and keeping it running when it breaks. The program is fully standalone —
PropertyLite is provided complete in Week 0, so there's nothing to build and no other track or
prerequisite required to start."
